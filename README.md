# How We Feel practitioner website exploration

A design exploration based on the practitioner page downloaded on October 6, 2026. Includes the animated hero, native scrolling 1–2–3 section, Marc Brackett audio player, practitioner stories, masonry reviews, and existing FAQ.

## Run locally

```sh
python3 serve.py
```

Open http://127.0.0.1:8765/practitioners.

This is a compiled website snapshot with custom CSS and JavaScript, rather than the original source project. External links and the podcast stream require an internet connection. How We Feel artwork and content belong to their respective owners; this repository is a team design exploration. Video.js license is included under assets/videojs.
